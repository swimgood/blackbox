blackbox

A black-box fuzzer for Quai smart contracts. Point it at any deployed contract and it throws randomized transactions at it — no source code required.

View on GitHub → Try the demo

What it does

Blackbox fuzzes deployed Quai contracts without needing the Solidity source. It reads the ABI, generates randomized and boundary-value inputs for every non-view function, and watches for behavior that shouldn't happen.

⬛

ABI-only black box

Works on verified contracts (auto-fetches from Quaiscan) or any contract with a manual ABI paste.

⚠

Detects panics

Overflow, underflow, assertion failures, and division by zero surface as decoded Panic codes.

⛽

Gas anomaly detection

Tracks per-function gas baselines and flags any call using more than 2× the median.

↺

Proxy-aware

Detects EIP-1967 and Beacon proxies, resolves the implementation, and loads its ABI automatically.

What it detects

  • Unexpected reverts — Panics from Solidity's built-in checks are flagged as likely bugs
  • Gas anomalies — a call using far more gas than usual suggests a loop or unbounded path
  • Custom errors — decoded by selector, matched against the ABI's declared error types
  • Invariant violations — storage slots or balances changing when they shouldn't

Install and run

Requires Node.js 18 or newer.

1
Clone the repo 
git clone https://github.com/swimgood/blackbox.git
cd blackbox/blackbox-fuzz
2
Install and build 
npm install
npm run build
3
Fuzz a deployed contract

Against any verified contract on Orchard testnet (Cyprus-1):

node dist/index.js 0xYOUR_CONTRACT_ADDRESS --zone cyprus1 --runs 200

Or, if the contract isn't verified, pass a local ABI:

node dist/index.js 0xYOUR_CONTRACT_ADDRESS --abi ./myabi.json
Note: Blackbox currently targets Orchard testnet (Cyprus-1) only. Fuzzing hits the testnet directly — QUAI on Orchard is free, so runs don't cost anything real. A local fork mode is on the roadmap.

CLI options

  • --zone <zone> — Quai zone, defaults to cyprus1
  • --rpc <url> — RPC endpoint override
  • --abi <path> — path to a local ABI JSON file
  • --runs <n> — number of fuzz iterations, defaults to 100
  • --seed <n> — fixed random seed for reproducible runs
  • --output <dir> — where JSON reports are written, defaults to ./fuzz-results
